# Privacy Policy & Restricted Permissions Disclosure for MANGAL

**Effective Date:** September 26, 2026  
**Application Name:** MANGAL (`ai.mangal.assistant`)  
**Architecture:** 100% Offline On-Device Android Voice Assistant

## 1. Zero Cloud Telemetry & Offline Guarantee
MANGAL processes all voice audio (`whisper.cpp`), wake-word detection (`openWakeWord`), language model inference (`llama.cpp`), and speech synthesis (`android.speech.tts.TextToSpeech`) strictly locally on your Android device.
- **No voice recordings, transcripts, prompts, contacts, calendar events, or SMS messages are ever transmitted to any external server.**
- Network access (`android.permission.INTERNET`) is used **exclusively** when you explicitly initiate an on-demand model weight download from Hugging Face in the **Model Manager** screen.

## 2. Encrypted On-Device Storage
All chat history and settings stored in the local Room SQLite database (`mangal_encrypted.db`) are encrypted at rest using **SQLCipher (AES-256-CBC)** with a 256-bit cryptographic key generated by `SecureRandom` and wrapped inside the hardware-backed **Android Keystore** (`MasterKey.KeyScheme.AES256_GCM`). Android Auto-Backup and device-to-device cloud extraction are explicitly disabled via `data_extraction_rules.xml`. You can permanently wipe all local conversation history at any time using the **Clear Memory** button.

## 3. Sensitive & Restricted Permissions Usage (Google Play Compliance)
MANGAL requests the following runtime permissions **strictly on-demand** when you issue a voice command that requires them:
- **`android.permission.RECORD_AUDIO`**: Used solely to capture 16 kHz mono PCM audio into an in-memory buffer for on-device speech-to-text (`whisper.cpp`). Raw audio frames are discarded immediately after transcription.
- **`android.permission.READ_CALENDAR` / `WRITE_CALENDAR`**: Used solely when you ask MANGAL to schedule a calendar event via `CalendarContract`.
- **`android.permission.SEND_SMS` / `READ_CONTACTS` / `CALL_PHONE` (Google Play Restricted Permissions)**:
  - Used **only** when you explicitly instruct MANGAL via voice/text to place a phone call or send an SMS message to a recipient.
  - **Play Console Notice:** Google Play restricts `SEND_SMS` and `CALL_PHONE` to default SMS/Phone handlers or approved voice-assistant accessibility/hands-free companion exceptions. If distributing on Google Play without Default Handler status, MANGAL supports switching `AndroidToolExecutor` to use `Intent.ACTION_SENDTO` (`smsto:`) and `Intent.ACTION_DIAL` (`tel:`), which pre-populate the system SMS/Dialer app with zero restricted permissions required.
